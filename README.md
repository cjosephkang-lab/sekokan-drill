# 施工管理ドリル

土木施工管理技士 第一次検定のスマホ向け学習アプリ。ログイン不要・1つのHTMLファイルで動きます。

## 運営
TechBull株式会社（お問い合わせ: cjoseph.kang@techbull.co.jp）

## 収録問題
- **1級 土木 第一次検定**：令和4〜8年度（問題A・B）
- **2級 土木 第一次検定**：令和4〜8年度（前期・後期）
- 出典：一般財団法人 全国建設研修センター 公表の試験問題・正答肢。各問題に年度と問題番号を表示しています。教材としての利用について同センターに確認しています。
- 正解番号は公式の正答表と照合しています。図・表を見る必要がある問題は除いています。
- 公式の解説は公表されていないため、解説欄には正解番号と出典を表示します。一部の問題にはAIが作成した解説を、その旨を明示して載せています（作成に利用者のデータは使っていません）。

## データの扱い
- 学習記録は、利用者の端末のブラウザ（localStorage）にだけ保存します。外部への送信はありません。
- ページを開いている間、外部のサイトへの通信はありません。

## 公開しているファイル
組み立て済みの `index.html` のみを公開しています。
