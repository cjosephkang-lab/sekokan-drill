# 施工管理ドリル（sekokan-drill）

土木施工管理技士 第一次検定のスマホ向け学習アプリ。ログイン不要・単一HTML・オフライン可。

## 学習エンジン
学習科学の定番2手法を実装：

- **間隔反復（SRS）**：間違えた問題は翌日、正解を重ねるほど間隔を広げて（1日→3日→7日→14日→30日）「忘れかけた頃」に再出題。2回連続正解で「習得済み」。
- **想起練習**：一度解いた問題も、開き直すと前回の答えは表示されず毎回「思い出して解く」形式。
- **今日やる導線**：試験日から逆算して1日の目標問題数を出し、復習→未着手→合格者推奨の科目順で自動出題。
- **予想得点**：科目別の正答率を本番の配点に換算して「あと何点で合格か」を可視化。1級は応用能力の足切り（総合60%かつ応用能力60%）に対応。

## 収録問題（公式過去問）
- **1級 土木一次**：令和5・6・7年度（問題A/B冊子）。
- **2級 土木一次**：令和5・6・7・8年度（前期）。
- 出典＝一般財団法人 全国建設研修センター（jctc.jp）公表の試験問題・正答肢。
- 正解番号は公式正答表と機械照合済み。図・表を要する問題は除外。公式解説は非公表のため、解説欄は正解番号＋出典を表示。

## 制度情報の出典
試験制度（受験資格・日程・合格基準・出題構成）はすべて国土交通省・全国建設研修センターの一次情報で確認済み。

## 技術構成
- 単一HTMLファイル（外部リソース依存ゼロ）
- 学習ロジックは `srs-engine.js` に純粋関数で分離、`srs-engine.test.js` でテスト済み（44 tests）
- `app-template.html` + エンジン + `questions*.json` を `build.py` で結合して `index.html` を生成
- 学習記録はブラウザの localStorage に級ごとに保存（サーバー不要）

問題・正答の著作権は全国建設研修センターに帰属します。本リポジトリは個人の学習を目的とするものです。
